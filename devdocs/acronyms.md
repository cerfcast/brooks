## Common Acronyms

- ps: Processing Stages (see, e.g., [CDNI Processing Stages Metadata](https://datatracker.ietf.org/doc/draft-ietf-cdni-processing-stages-metadata/))
- md: Metadata (see, e.g., [Content Delivery Network Interconnection (CDNI) Metadata ](https://datatracker.ietf.org/doc/rfc8006/))
- imd: Interconnection Metadata (e.g., `HostMetadata`, `PathMetadata`) (see, e.g., [Content Delivery Network Interconnection (CDNI) Metadata ](https://datatracker.ietf.org/doc/rfc8006/))
